# EXP-028：异步任务编排的可靠性与幂等执行

## 1. 实验目标

验证同一个异步任务重复提交时，如何通过 ConcurrentHashMap 和 FutureTask 实现 JVM 内存级幂等执行。

## 2. 实验环境

- JDK 25
- Maven
- JUnit 5
- ConcurrentHashMap
- FutureTask
- ThreadPoolExecutor / ExecutorService

## 3. 实验结果

| 场景 | 提交次数/任务数 | 实际执行次数 | 结果 |
|---|---:|---:|---|
| A 顺序重复提交 | 10 | 1 | 通过 |
| B 并发重复提交 | 100 | 1 | 通过 |
| C 不同任务并行 | 3 | 3 | 通过 |

Maven 测试：3/3 通过，0 失败，0 错误。

执行耗时：0.660 秒。

## 4. 核心技术结论

1. ConcurrentHashMap.putIfAbsent 可以保证同一 taskId 只登记一个任务。
2. 重复提交返回已有 FutureTask，可以复用同一执行结果。
3. 不同 taskId 可以独立执行，不会互相覆盖。
4. JVM 内存级幂等只能解决单进程内的重复提交问题，无法直接解决多实例部署下的任务重复执行。

## 5. 当前实现的风险

任务记录先写入 Map，再提交线程池。如果线程池拒绝执行，Map 中可能保留一个永远无法正常完成的 FutureTask。

其他请求重复提交时会继续拿到这个 FutureTask，导致等待或异常处理问题。

## 7. 验收结论

EXP-028 第一阶段通过。顺序重复提交、100 线程并发重复提交、不同任务隔离三项实验全部通过。

当前实现仅用于 JVM 内存级幂等实验，不代表已经具备生产级任务可靠性。
